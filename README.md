# OmniMate – Your AI-Powered Personal Assistant

OmniMate is an AI-powered personal assistant designed to provide information and answer user queries through a simple, interactive chat interface. Built using React, Vite, Node.js, and Express, it integrates Google's Gemini AI with external APIs to deliver real-time information and intelligent responses.

### Key Features
- **AI-Powered Chat:** Interact with Gemini AI to ask questions and receive contextual responses.
- **Conversation Memory:** Maintains previous chat history to understand follow-up questions and provide context-aware answers.
- **Weather Updates:** Get current, historical, and forecast weather information using WeatherAPI.
- **Cryptocurrency Insights:** Retrieve cryptocurrency prices, historical data, comparisons, and market trends using CoinGecko.
- **Latest News:** Fetch news articles and updates based on user queries using GNews.
- **Persistent Chat History:** Stores conversations in browser localStorage.
- **Interactive UI:** A responsive Neo-Brutalist interface built with React and Tailwind CSS.

### Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **AI Integration:** Google Gemini API
- **External APIs:** WeatherAPI, CoinGecko, GNews
- **Storage:** Browser localStorage

OmniMate aims to bring multiple information services into one unified AI-powered conversational experience.
